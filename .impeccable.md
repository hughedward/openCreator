## Design Context

### Users

This is a single-user, local-only tool for its developer. Its job is to turn
model calls that could already be made in code into a faster, pleasant visual
workflow for ongoing chat, image generation, and video generation.

### Brand Personality

Quiet, precise, and capable. The interface should feel calm during long prompt
sessions and trustworthy when tasks take time.

### Aesthetic Direction

Refined monochrome minimalism with a warm paper-like light theme. Use strong
typographic hierarchy, hairline separators, generous whitespace, and restrained
motion. It may borrow ChatGPT's familiar conversation structure but should not
look like a generic dashboard or a collection of floating cards. Avoid
gradients, neon AI styling, excessive rounding, glass effects, and decoration
without purpose.

### Design Principles

1. Keep the prompt and generated work visually dominant.
2. Reveal model-specific controls only when they are relevant.
3. Make asynchronous generation state obvious without making the screen noisy.
4. Prefer typography, rhythm, and alignment over ornamental containers.
5. Keep every core action usable by keyboard and on a narrow viewport.
